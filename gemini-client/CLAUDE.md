# gemini-client

A shared, browser-safe Gemini API (Google AI Studio) client for Ben's apps: the models list and video generation, with the API key passed in, plus a Node-only CLI (`gemini-video`) that renders clips to MP4 files. A Benhäus credential adapter (`package.json` › `benhaus.credential`).

Started 2026-11-02 from a Claude Code session; this file is the brief and the state.

## Brief
What Ben asked for:
> a gemini adapter so we can generate videos with it

The session that built it was told: an adapter like resend-client (credential "Gemini (Google AI Studio)", field apiKey, env GEMINI_API_KEY, tested with a GET of the models list with `x-goog-api-key`, hints for an invalid key and a disabled API); a browser-safe library on http-kit with models.list and video generation with Veo (the long-running predict, get the operation, wait with backoff and an AbortSignal, download the bytes), typed errors like Resend's, a per-second price table with its date and source; a Node-only CLI that loads credential `gemini/toejam` (field apiKey, env GEMINI_API_KEY) with benhaus-client's loadCredential, takes a prompt or a JSON file of jobs, prints the run's estimated cost first, needs `--yes` to spend and has `--dry-run`. First use: stand-in clips for a toejam music visualizer, vertical 9:16 phone-style bar and club scenes. No paid call and no real generation while building (no key yet).

## What Google's docs said on 2026-11-02 (read, not remembered)
- **Veo is no longer on the Gemini API.** aistudio.google.com/docs/deprecations (ai.google.dev/gemini-api/docs/* now 301s to aistudio.google.com/docs/*): `veo-3.1-generate-preview`, `veo-3.1-fast-generate-preview`, `veo-3.1-lite-generate-preview` shut down 2026-10-22; `veo-3.0-generate-001`, `veo-3.0-fast-generate-001`, `veo-2.0-generate-001` from 2026-06-30. Replacement: `gemini-omni-1.1-flash` (Gemini Omni Flash, GA 2026-08-27, no shutdown date), or Veo 3.1 GA on the Gemini Enterprise Agent Platform (Google Cloud, not an AI Studio key). aistudio.google.com/docs/video is now a shutdown notice pointing at Omni.
- **Gemini Omni Flash** (aistudio.google.com/docs/omni): `POST https://generativelanguage.googleapis.com/v1beta/interactions`, body `{ model, input, response_format: { type: "video", aspect_ratio: "9:16" | "16:9", resolution: "360p" | "720p" | "1080p" | "4k", delivery: "inline" | "uri" }, generation_config: { video_config: { task } }, background, store }`. Synchronous by default; the video is in `steps[]` (type `model_output`) › `content[]` (type `video`) as base64 `data` or a Files API `uri` (download `GET /v1beta/files/{id}:download?alt=media`). No duration, negative prompt, seed, person generation, sample count or audio toggle fields. Images as `{ type: "image", data, mime_type }` input items (`<FIRST_FRAME>`, `<LAST_FRAME>`, `<IMAGE_REF_0>` in the prompt). SynthID on every output.
- **Price** (aistudio.google.com/docs/pricing): paid tier only, no free tier. Output video $17.50 per 1M tokens, 5,792 tokens per second of 720p, "approximately $0.10 per second". Input $1.50 per 1M.

- **Interactions API** (aistudio.google.com/api-reference/interactions-api, /docs/background-execution): `GET /v1beta/interactions/{id}`, `POST …/{id}/cancel`, `DELETE …/{id}`; `status` is `in_progress`, `requires_action`, `completed`, `failed`, `cancelled`, `incomplete`, `requires_continuation`; `errors[]` of `{ code, message }`; `usage.output_tokens_by_modality`. `VideoResponseFormat` has `duration` (a string, no format given). `background: true` needs `store: true`; stored 55 days on the paid tier. GET returns the video inline even for `delivery: "uri"`.
- **Billing** (/docs/billing, /docs/rate-limits): set up billing on the key's project in AI Studio, prepay ≥ $5 or Postpay; Tier 1 at once ($250 monthly cap, $10 per rolling 10 minutes). The $300 Cloud credit doesn't cover the Gemini API.

## State
Built 2026-11-02, nothing sent to Google (no key yet): `src/client.ts` (http-kit; `x-goog-api-key`; JSON calls and a byte download that only ever sends the key to the API's origin), `src/errors.ts` (`GeminiError`/`GeminiAuthError`, `category` auth/setup/validation/not_found/rate_limit/blocked/other, ErrorInfo `reason`, `quotaIds`), `src/models.ts`, `src/video.ts` (Omni Flash: `request`, `start` in background, `get`, `wait` with backoff, `download`, `generate`, `cancel`, `delete`; Veo ids refused), `src/pricing.ts` (`VIDEO_PRICES`, `TOKEN_PRICES`, estimates, `costOfUsage`, `RETIRED_VIDEO_MODELS`), `src/bytes.ts`, and the CLI in `src/cli` (`jobs.ts` pure, `run.ts` with injected IO, `gemini-video.ts` the bin). 57 tests against the fake fetch in `src/fake-fetch.test.ts`, all passing; build and typecheck pass. README.md is the reference.

Decisions: built on Omni Flash because Veo is gone from the Gemini API (the brief asked for Veo); `start` retries only a 429 (a 5xx might have started a paid clip); the CLI defaults to 9:16 and 720p, sends `seconds` only when asked, estimates an unspecified clip at 10 s, needs `--yes` to send anything, and keeps each started clip's id in `<out>/.gemini-video/<name>.json` so a stopped run resumes without paying twice.

Unverified until the first paid run: the `duration` string format ("8s"), the token rate for 1080p/4K/360p (assumed 720p's), and the shape of a safety-blocked interaction. Next: Ben adds the key (`gemini/toejam`) with billing on its project, a `--dry-run` then one 8 s clip with `--yes`, and this file and the README get what that run shows.
